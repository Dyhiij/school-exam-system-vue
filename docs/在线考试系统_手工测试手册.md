## 4. 缺陷复现路径（写测试报告"缺陷发现"章节用）

若想在报告中演示"修复前会怎样"，可对照代码说明（无需真跑旧版）：

1. **成绩不落库**：修复前 `ExamController.submitExam()` 只 `return` 计算出的分数，无任何 insert；
   现改为成绩 upsert 进 `exam_score` + 明细进 `exam_answer`（唯一键 batch_id+user_id 防重）。
2. **判分不分卷**：修复前遍历 `question_bank` 全部题目判分（与试卷无关）；
   现通过 `exam_paper_question` 关联表只取本卷题目判分。
3. **简答丢失**：修复前代码注释 `// todo: save subjective answer`；
   现 `exam_answer` 表存主观题作答与参考答案，供教师阅卷。
4. **登录态不持久**：修复前 `user_info` 无人写入 localStorage，页面刷新即回登录页、考生名永远占位；
   现 `Login.vue` 成功后写 localStorage('user_info')，`store` 初始化时恢复。

（详见《缺陷修复说明_v3.md》第七节"代码级修复位置速查"）

## 附录 A：客观题答案（演示用全对路径）

试卷 1 绑定题目：1、2、3、4（客观，各 20 分）+ 6（简答，20 分）。判分按**字符串比对**：
- 单选/判断：选项字母（如 A / 对 / 错，以页面显示为准）
- 填空：文本框逐字比对，注意前后无空格
- 不确定答案时：先点开"查看题目"对照题库，或全部选 A 走"部分得分"路径也可验证判分

> 提示：交卷前可**故意答错 1 题**再交，验证不是全给满分（判分真实性），
> 预期客观得分 60（3 对 × 20）；然后教师阅卷给简答 20 → 总分 80。此路径更能体现"按卷判分+人工阅卷"双闭环。
